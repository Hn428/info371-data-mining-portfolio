# Project Proposal: Smartphone Usage, Sleep, Stress, and Productivity

## Data Context

This proposal references `Smartphone_Usage_Productivity_Dataset_50000.csv` from Kaggle. The dataset is not currently included in this repository.

## Proposed Data Mining Work

The project proposes analyzing smartphone usage, sleep, stress, and lifestyle patterns to predict productivity and stress-related outcomes using regression and classification techniques.
