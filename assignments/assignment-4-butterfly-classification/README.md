# Assignment 4: Butterfly Image Classification

## Data Context

This assignment uses `data/butterfly_labels.h5`, an HDF5 dataset containing butterfly `images` and `labels`. The notebook describes 75 butterfly classes and 6,499 labeled images.

## Data Mining Work

The notebook inspects image labels and pixel ranges, normalizes image arrays, encodes labels, splits train/test data, and compares a dense neural network against a CNN-style model.

## How to Run

Open `assignment4.ipynb` from this folder. Full model training may take time and is better run with GPU support.
