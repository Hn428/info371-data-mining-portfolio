# Assignment 3: IMDB Sentiment Classification

## Data Context

This assignment expects `data/imdb_reviews_5k.csv`, a 5,000-review IMDB sentiment dataset with review text and positive/negative labels. That dataset is referenced by the notebook but is not currently included in this repository.

## Data Mining Work

The notebook compares text vectorization strategies with multiple classifiers, including KNN, decision tree, random forest, and multinomial naive Bayes. Evaluation uses precision, recall, and F1 score.

## How to Run

Add `imdb_reviews_5k.csv` to this folder's `data/` directory, then open `assignment3.ipynb`.
