# Assignment 1: Stack Overflow Survey and KNN Classification

## Data Context

This assignment uses two datasets:

- `data/stackoverflow_survey_results.csv`: Stack Overflow developer survey data with professional, education, employment, technology, and salary-related fields.
- `data/exam_data.csv`: a small synthetic exam dataset with `HoursStudied`, `ExamScore`, and `Passed`.

## Data Mining Work

The notebook frames a prediction objective using developer survey features, then applies K-nearest neighbors classification to predict pass/fail outcomes from exam study and score variables.

## How to Run

Open `assignment1.ipynb` from this folder. The notebook expects its data files under `data/`.
