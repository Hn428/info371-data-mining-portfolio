# Assignment 2: NBA Game Outcome Prediction

## Data Context

This assignment uses `data/nba_2024.csv`, a 2023-2024 NBA schedule/results dataset containing game dates, visitor and home teams, points, attendance, arena, and notes.

## Data Mining Work

The notebook creates a `VisitorWin` target, one-hot encodes visitor teams, engineers recent-win features, and compares decision tree and random forest classifiers using cross-validation and grid search.

## How to Run

Open `assignment2.ipynb` from this folder. The notebook expects `data/nba_2024.csv`.
